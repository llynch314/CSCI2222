Three Big Network Protocols

  1. Hypertext Transfer Protocol (HTTP)
    • A layer 7 protocol used to transfer data between systems on the World Wide Web.
    • Different from HTTPS
  2. Transmission Control Protocol (TCP)
    • A connection oriented transport layer that provides reliable and ordered data delivery
    • Used in email, FTP, web browing, and streaming services
  3. User Datagram Protocol
    • Is a connectionless transport layer that provides fast but unreliable data transmission
    • Does not establish a connection before sending data
